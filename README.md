# Nous

Petit espace privé à deux : chat en temps réel, photos partagées, agenda commun.
Next.js (App Router) + Supabase (base de données, stockage, temps réel),
hébergé sur Vercel.

## Comment ça marche

- **Connexion** : un seul code secret, connu de vous deux.
- **Chat** (`/chat`) : messages texte et photos, en direct.
- **Photos** (`/photos`) : galerie partagée.
- **Agenda** (`/agenda`) : calendrier mensuel.
